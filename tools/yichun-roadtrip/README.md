- 用户历史截图469km/5h29是伊春市→鹿苑→世茂大道的当时结果，不是10.8预测，不含机场接驳；此前504km/6h52含旧途经点，不能复用到新路线。
- 地图是区域/行程关系示意，不宣称经纬度投影或导航道路。门票官方定价与前版平台预算分开标识；不保证票库存及不限流。
