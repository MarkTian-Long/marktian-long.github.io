# Blog 图片生成与视觉验收清单

版本：1.1｜更新：2026-11-28

本清单是**单张图片从候选到入稿的质量门禁**。它不替代图表语义规范、VISUAL_GUIDE 的尺寸/许可契约、Checklist 0.13 的首图交付检查或网页浏览器验收。

## A. 生成前：任务门

每张图必须先有 brief：

- [ ] 有明确插入位置和独立阅读任务，不是为了装饰或填充篇幅。
- [ ] 能用一句话说明该图要帮助读者理解什么。
- [ ] 主体、动作、关系和关键限制已经明确。
- [ ] 已区分事实、概念隐喻和未知；没有要求模型虚构数字、UI、品牌或真实现场。
- [ ] 已选择合适媒介：概念/场景图优先生图；纯数据图、真实证据图和精确截图走对应来源或确定性制作。
- [ ] Prompt 指向独立图片资产，不是网页、文章截图、幻灯片或整篇拼图。
- [ ] 提示词只包含当前图片对应的局部内容和一个视觉命题；未把全文、完整大纲、多个章节摘要或所有 KPI/案例作为背景。
- [ ] 最终发送的提示词已复核，未混入助手说明、流程讨论或前一轮无关文本；若是框架图，节点均属于同一逻辑结构。

未通过任务门，不调用生图。

## B. 候选图：硬性拒绝条件

出现以下任一情况，直接 Reject，不进入正式资产目录：

- [ ] 输出媒介错误：生成了网页截图、UI mockup、整页文章、拼贴或多章总览，而需求是独立正文图片。
- [ ] 输出虽然是单张图片，却以总标题 + 多个章节/模块/编号卡片概括全文；这类全文摘要海报一票否决。
- [ ] 图像把互不相属的章节论点、案例、指标和结论拼在一起；不得以裁切或删除标题补救。
- [ ] 核心主体、对象数量、关系、方向、因果或边界与 brief 不符。
- [ ] 出现未经来源支持的数字、数据、品牌、Logo、产品 UI、客户现场或看似真实的研究证据。
- [ ] 文字有错字、漏字、乱码、重复、单位错误，或关键文字不可读。
- [ ] 重要对象被裁切、遮挡、变形，或图意容易产生相反理解。
- [ ] 图片只有通用装饰，没有清楚主体或视觉重点；与正文任务没有可说明的关系。
- [ ] 视觉语言明显偏离文章已确认的风格锚点，且无法通过小范围编辑修正。
- [ ] 缩小到实际正文宽度后，主体/关系/必要文字无法辨认。
- [ ] 图片尺寸、格式、字节大小、来源许可或静态安全不满足 VISUAL_GUIDE / 图片契约。

硬性拒绝不能由其他优点抵消。

## C. 视觉质量评分

对通过硬门的候选，按 1–3 分逐项评估。1 = 不合格；2 = 达到可用标准；3 = 明显优秀。**每项必须至少 2 分**，不以平均分抵消某一项明显失败。

| 维度 | 1：不合格 | 2：可用 | 3：优秀 |
|---|---|---|---|
| 阅读任务与主体 | 看不出图要解释什么 | 主体和任务清楚 | 一眼建立问题入口或机制理解 |
| 视觉层级 | 主次混乱、没有焦点 | 有明确主焦点和次级信息 | 视觉动线自然，层次有节奏 |
| 构图与空间 | 拥挤、空洞或机械对称 | 比例、留白和空间关系合理 | 构图有张力，空间关系帮助理解 |
| 视觉表现 | 通用图库/默认卡片感 | 风格明确、质感和光线合理 | 有辨识度，细节与隐喻服务论点 |
| 系列一致性 | 与同篇其他图不协调 | 色彩、材质、字级基本统一 | 共享视觉语言但每张构图有差异 |
| 阅读尺度 | 手机缩放后关键内容丢失 | 手机和桌面均能辨认 | 缩小后仍有清楚焦点，细节可按需放大 |

评分结果：____ / 18；六项最低分：____。任何一项低于 2 分，返工或拒绝。

## D. 精确图 / 流程图的语义门

如果图片承担精确论证，额外检查：

- [ ] 节点/对象全集与冻结逻辑源一致。
- [ ] 每条连线的起点、终点、方向和含义一致。
- [ ] 分支条件、循环、异常路径、人工介入和终点一致。
- [ ] 数字、单位、图例、颜色语义与真实数据一致。
- [ ] 模型没有新增、删除、合并或重排节点。
- [ ] 中文标签由精确排版层承载，或已逐字校对。
- [ ] 保留可编辑的 SVG/HTML 逻辑源；生成式位图不冒称可编辑图表。

任一语义偏差即拒绝。可保留生成图的视觉风格，再用确定性图层重建准确关系。

## E. 入稿前资产门

- [ ] 选定的是独立最终资产，废弃候选未进入正式资产目录。
- [ ] 实测像素尺寸、宽高比、文件格式和文件大小。
- [ ] 检查主体边缘、压缩瑕疵、文字、裁切安全区和实际显示比例。
- [ ] alt 准确描述图片信息；caption 说明必要来源/示意边界，不复述整段正文。
- [ ] 记录工具、Prompt、参考图角色、修改轮次和制作说明。
- [ ] 写入正确的 assets/images/blog/<slug>/ 路径，并与 Markdown/metadata/预览登记保持同源。
- [ ] 真实网页中通过桌面/移动、浅色/深色主题检查；图片加载成功不等于清晰度通过。
