# A股 AI 研究助手

> 六 Tab 研究会话：把数据模式、证据来源、任务步骤、反馈与治理边界放在同一条可复核链路中。

## 功能概览

| Tab | 作用 | 可见边界 |
|-----|------|---------|
| 💬 行情助手 | 自然语言解析 → 行情快照 → 本地规则摘要 | 默认固定演示快照；联网行情必须先由用户切换并提交，成功或失败都会显示 |
| 🔬 个股诊断 | 行情、基本面、情绪三类证据卡 | 显示来源覆盖、数据时间和待核查项，不输出买卖判断 |
| 📄 研报生成 | 查询扩展、关键词召回、规则重排、逐 Claim 引用与反馈 | 固定资料可回溯到 `sourceId`；不声称模型效果或引用准确率 |
| 📡 市场雷达 | 固定板块、异动、情绪趋势与规则简报 | `asOf=2026-08-28T07:00:00.000Z`，重绘保持确定性，不代表实时市场 |
| 🤖 Agent 实验室 | 识别任务 → 选择工具 → 执行 → 汇总证据 | 只选择任务相关工具；对象未识别或工具失败时保留 `partial`，不猜测、不下结论 |
| 🛡️ 合规设计 | 数据血缘、标注字段与治理提示 | 是产品设计演示，不是法规意见或生产合规证明 |

## 技术架构

- **前端**：Vanilla JS + CSS3，零依赖，无构建步骤。
- **统一会话**：`StockResearch` 暴露研究 API；每次运行记录 `runId`、场景、数据模式、来源编号、状态和版本，仅保留在当前页面内存。
- **行情契约**：`market-snapshot` 统一返回 `source`、`transport`、`marketAsOf`、`fetchedAt` 和数值型 `rows`。
- **联网模式**：仅用户主动选择“联网行情”并提交查询后请求 Yahoo Finance；依次尝试公开代理。HTTP、超时、解析失败或全部失败均显示错误，不静默换成演示数据。
- **固定演示模式**：行情、雷达、基本面、情绪和新闻使用代码内固定快照；不读取当前时间，不制造随机结果。
- **RAG**：金融同义词扩展、关键词召回和来源层级规则重排均在本地执行；每个 Claim 带 `sourceId`、证据级别、`asOf` 和未解决冲突提示。
- **私有资料**：用户粘贴内容只进入当前页面内存，参与本地关键词召回；关闭页面即清除，不上传、不写入 `localStorage`。
- **历史本地工具**：`proxy.py` 保留作历史本地 Tushare 代理参考，未参与公开页面，本页不调用它。

## 数据与内容标注

- **演示快照**：固定行情样本，展示 `marketAsOf` / `fetchedAt`。
- **固定资料**：新闻、财务和情绪样本，展示 `sourceId` / `evidenceLevel` / `asOf`。
- **联网成功**：只在用户主动模式下出现，展示 Yahoo 来源和实际传输代理。
- **联网失败**：显示失败原因、当前模式和重试/改用演示快照操作，不替换为另一种结果。
- **本地规则**：用于意图、摘要、召回、重排和 Agent 任务选择，不等同于模型生成或预测能力。

## 五类来源

1. **外部快照**：用户主动联网后收到的 Yahoo Finance 响应，带 `source`、`transport`、`marketAsOf` 和 `fetchedAt`。
2. **演示夹具**：代码内固定行情、新闻、基本面、情绪与 Radar 快照，用于稳定复现。
3. **本地计算**：区间涨跌、关键词召回、规则重排、证据完整度和 Agent 工具选择。
4. **静态文案**：页面中的治理说明、免责声明、操作提示和待核查边界，不是数据或模型输出。
5. **用户输入**：查询对象、研究任务、反馈和粘贴的私有资料；私有资料仅存在当前页面内存。

## 反馈回归

研报草稿下方的反馈条为每个 `runId` 只接受一次最终反馈：采用、需修改或标记问题。需修改/问题记录包括问题类型、修复对象和回归结果，并可导出 JSON；记录只存在当前页面内存，不伪装成线上训练闭环。

## 安全与治理边界

页面不加载 `config.local.js`，不携带 credential，不调用外部模型。所有研究结果仅用于产品流程演示，不构成投资建议，也不替代人工研究、适当性评估、数据核验或交易授权。若未来接入真实模型或生产数据，必须另行设计服务端代理、最小权限、审计和人工确认。
