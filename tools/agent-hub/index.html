AGENT COGNITION / FIELD GUIDE 01

Agent 认知全景：先判断任务，再决定 Agent。

把“要不要上 Agent”拆成六个可回答的问题：先识别任务边界，再选择自动化、检索增强、工具型单 Agent、并行多 Agent或人工评审。

这是静态规则判断：不调用模型、不接入生产数据，也不代表生产数据或效果。结论只用于帮助你形成方案假设，最终上线前仍需用真实数据复核。

02 / design for failure

架构不是拓扑图，是故障边界。

四种常见组合都标出适用条件、故障传播、重试边界和停止边界。越复杂的拓扑，越需要先证明它值得维护。

03 / scene presets

场景预设：让判断落到业务。

预设不是答案，而是一组可以被替换的起点。点击“用此场景预填”，回到六问决策器检查假设是否成立。

04 / product judgment

把观点写成可复核的判断。

每条判断都带适用条件、反例和下一条证据需求，避免把漂亮的 Agent 叙事误当成通用规律。
