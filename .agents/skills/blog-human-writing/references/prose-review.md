# 自然中文与段落推进

> 本文是 `.agents/skills/blog-human-writing/` 的权威子规则。真实执行活人感审校时读取这里的当前版本；运行时入口和兼容副本不得独立改写它。

初稿完成后进行活人感审校时读取全文；规则是语义判断，不是禁词表。

## 写作原则

### 让作者站在材料旁边

- 写清作者凭什么知道：亲历、检索或判断各归其位；没有亲历时不补写现场、对白、动作、神态或心理。
- 第一人称只在真实经历或明确判断能增加信息时出现；不靠“我觉得”“说真的”制造声音。
- 改写只重组、压缩和澄清已有材料；不能为了具体或顺滑补出新的流程、角色、案例、数字、原话或因果判断。

### 让每段完成一个自然推理任务

- 段落边界由自然推理任务决定。共同完成一次连续推理的事实、解释、例子、边界和结论优先保留在同一自然段。
- 后一段接住前一段留下的问题、后果或限制；不用“更深一层”“真正的问题”等路标假装推进。
- 每个段落要推进事实、动作、例子、区别、后果、有依据的判断，或概念边界、关系与总结。
- 同一观点只完整展开一次；背景知识只在解释选择、改变风险、提供尺度或构成反例时加入。

### 让中文主干早点出现

- 优先先写清谁做了什么，再补时间、原因、条件和例子。
- 将遮蔽动作的名词化表达还原为具体动作和结果；确实提供精度的专业名词保留。
- 不让多层定语和连续“的”把主语、动作或判断压到末尾；关键词可自然重复，不为躲重复频繁换近义词。

### 保留真实节奏

- 段落和句子的长短来自推理任务与内容复杂度，不建立固定句数或字数规则。
- 不通过机械拆句、增加换行或反复“观点—解释—总结”制造节奏；单句段只用于确实需要停顿的钩子、关键问题、明显转折或推理落点。
- 不添加网络梗、粗口、错别字、括号吐槽或生活细节表演“活人感”。

## 审校顺序

1. **作者位置与事实边界**：删除无来源的假具体，区分事实、机构说法、媒体概括、作者推断和未知；无法核准的亲历、现场或引语先省去或集中询问。
2. **段落功能与信息增量**：给每段标出自然推理任务；连续几段完成同一推理链时优先合并或改善句间关系；无法指出新增信息的段落通常压缩。
3. **表演性表达**：检查是否制造不存在的误解再翻案、用空路标代替逻辑桥接、连续制造金句、用无关比喻或堆叠术语抬价。真实概念校正、专业术语、必要排比和有效比喻保留。
4. **模板化审稿腔与认知轨迹**：必要边界可以保留；若只是显得谨慎或专业，改为“事实/证据 → 判断 → 必要边界”。不要把本轮搜索、编辑发现或对话结论伪装成作者“后来发现”“越来越觉得”；时间性认知表达需有作者经历、正文前文、真实历史观点或清楚时间过程支持。
5. **句法、节奏与结尾**：检查主语和动作、名词化表达、长定语和段落边界；结尾回到标题、摘要和主结论，不重列全文、不硬造升华或引入新尺度。

## 修改后的保护性复核

确认事实、数字、单位、时间、比较对象、直接引语、来源归属和判断强度未被改写过头；行内链接和术语保持；没有为节奏拆碎推理或删除必要的不确定性、反例与适用条件；Markdown 标题、唯一摘要 blockquote、表格、代码和图表结构未被破坏。随后执行完整 `blog-review-checklist` 并修复确定性问题后再交付。
