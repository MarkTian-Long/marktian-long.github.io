# Blog 首图、隔离预览与分享文字自动化

状态：实现完成，以下执行记录截至提交前；提交后的浏览器与部署结果以关联 CI 和本轮实际交付核验为准。基线：`de13690cffe89f9dd94504d7f277656b5d912b6e`。

## 目标与边界

把已经稳定的首图与预览契约落实成可执行检查，修复分享图摘句的主线偏移，并清理会覆盖新规则的陈旧入口。沿用现有目录分工、正式模板和单一 Markdown，不新增同义工作流 Skill、不修改 CI 权限、不自动发布草稿。当前用户已授权本轮工具、规范与已发布文章分享文案的修改；此授权不扩展为任何新草稿的公开预览或正式发布授权。

## 实施任务

1. **首图检查与候选预览**：在 `scripts/` 增加可复用的正文首图检查，在 `tools/blog/` 增加隔离预览入口。复用当前源稿解析、图片契约、正式模板和公开文件白名单。默认检查，写入仅限显式候选输出；预览无索引、无虚构发布日期，静态展示当前 tags/topics。草稿 metadata 不写入正式 posts-meta。历史已预览或作者首图例外必须携带理由与证据，不设置无理由跳过开关。
2. **分享图文字**：保留 title、summary、share_quote 三字段，发布脚本只校验来源并同步，不自动选择观点。将《黎曼猜想之后》摘句替换为正文中已有的主结论。修复无障碍文本遗漏摘要、重复标点；保留完整文字与当前视觉设计。
3. **规范与入口**：执行细节写回预览规范、工具 README 与现有 publish-blog Skill；分享编辑标准由 Writing Guide 维护，SOP 路由、Checklist 验收。清理 CONVENTIONS、memory、sync-docs 中的旧规则。新增可复制的网页版项目指令薄入口，保留长期硬约束，按职责链接当前 GitHub 规范。
4. **集成验证**：新增行为先观察失败再实现；检查路径越界、符号链接、缺图/位置错误、例外追溯、候选输出隔离、正式索引不变、无障碍文字保真。运行受影响测试、仓库全量测试、资产与分发检查；实际查看当前文章分享图。没有证据的视觉问题不顺手重构。
5. **交付与回读**：统一审查完整差异，最小修复重要问题；核对远端并发后提交并回读，分别报告仓库、CI、部署及真实界面结果。网页版项目设置仅在实际可访问并完成保存后报告更新，否则交付仓库中的同一可复制入口并明确未改设置。

## 接口与分工

- 首图与预览实现共同拥有生成器接口，输出命令确定后由集成任务更新文档，避免文档先写不存在的命令。
- 分享任务仅维护分享规则对应段落、海报运行时/测试及本篇源稿和派生 metadata；不改正文、标题、摘要或历史文章。
- 指令整理任务维护通用入口、共享上下文和 sync-docs；不重复维护专项细节。
- 候选目录、测试日志与截图均为可复现临时产物，不进入公开白名单或 Git。

## 人工判断保留项

脚本不能判断图片是否忠实、摘句是否代表主线、事实是否成立，也不能证明作者已授权。自动报告只说明实际检查到的来源、布局、路径与状态；内容判断、浏览器视觉验收和独立发布授权仍按当前规范完成。
