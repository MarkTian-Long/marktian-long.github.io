# 首页写作区推荐阅读设计

## 目标

让首页的「思考碎片」更清楚地表达内容积累与阅读入口，同时保留现有克制、文字优先的视觉风格。

## 已确认的约束

- 不使用「本月推荐」：推荐应是长期有效的人工编辑选择。
- 不生成、改写或截断文章摘要：首页继续使用 `posts-meta.json` 中现有的 `summary`。
- 不添加封面图、阅读时长、互动数据或自动推荐。
- 不改变博客归档页的精选阅读机制；它仍可展示最多三篇精选文章。

## 方案

首页从 `featured-posts.json` 读取第一篇有效文章，渲染为单独的「推荐阅读」主推行；再从文章顺序中选择三篇不重复的最新文章，作为普通列表行。主推与普通行都展示既有日期、标题、摘要和标签。CTA 在成功加载元数据后更新为「浏览全部 N 篇文章 →」，其中 N 为实际文章数量；加载失败时保留静态的「查看全部文章 →」。

视觉上只使用现有的颜色、字体、边框和圆角变量。主推行以轻背景、上方的小型栏目标签和右侧阅读提示形成层级；不引入新的卡片体系。

## 验收

- 首页在有效精选配置下显示 1 篇「推荐阅读」与 3 篇「最近更新」。
- 首页使用完整的现有摘要，CTA 正确显示实际文章总数。
- 精选配置缺失或读取失败时，首页仍能回退为最新文章列表与原 CTA。
- 桌面和手机视口中无横向溢出，主推与普通列表层级清晰。
