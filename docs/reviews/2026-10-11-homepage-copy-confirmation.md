## 新模块修正依据（r2）

- 红框文字用于提示入口/环境与成熟度。本轮简化为「Windows 本地运行」「ChatGPT 网页版 · Windows · 试用版」「起步框架 · 试用版」，安装依赖版本留在使用说明。
- 文件助手优先说明网页版通过安全隧道远程读取授权本机资料。资料能被获取不等于永远留在本机：返回内容仍发送给 ChatGPT。
- [官方用量说明](https://help.openai.com/en/articles/20001354-gpt-6-and-other-models-in-chatgpt)区分 Chat 与 Work/Codex 用量规则；[连接说明](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)支持在 ChatGPT 创建 Tunnel 插件。普通 Chat 路径应按 Chat 规则计量是据此作出的判断，不是本轮项目级扣额实测。网页同样能使用 Work，首页不写无条件「不消耗 Work 额度」。
- Harness 重新参考[博客原文](https://marktian-long.github.io/tools/blog/posts/personal-harness.html)，聚焦让历史背景、判断与有效纠偏进入下一次协作，以及公开项目提供可自行发展的起步骨架。线上正文读取失败后核对了 GitHub 正式 HTML（文件 SHA `679ce30df51185477ca4217451a48eb8bdb54fd1`）与本地正文；不把个人系统全部能力投射给公开 starter。
- Harness 当前介绍：「让每一次与 AI 的合作，成为下一次的起点。从轻量框架开始，逐步沉淀自己的背景、判断与工作方法。」
