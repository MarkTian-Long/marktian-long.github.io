# 工具与工作流：本地实施与验收

日期：2026-10-09。首轮本地实现和视觉复核已完成。以下至「第二轮」之前均为四项目版本的历史验收；精简版本的结果在文末单独追加。未暂存、提交、推送或部署。

## 实施结果

- 首页以「工具与工作流」接替独立的「我的判断」，精选 AI 本地文件助手、多平台资料库、AI 每日情报、Codex 动态监测四项。每项展示用途、使用条件、使用说明和 GitHub 仓库。
- 导航改为文章 / 工具 / 作品 / 案例 / 联系。原「作品 & 工具」更名为「原型与研究」，八个作品的 ID、链接和顺序保持一致。
- 博客归档增加独立的站点导航入口，桌面位于侧栏，手机位于标题之前；分类、搜索与精选机制保持。
- 旧 `#about` 指向个人介绍。旧观点及附属内容逐字保存于 `docs/plans/archive/2026-10-09-homepage-judgment-snapshot.md`，已与修改前源码核对。
- 公开文件仅修改 `index.html`、`assets/css/style.css`、`tools/blog/index.html`。文章、文章元数据及其余白名单资产与修改前快照逐字节一致。
- README、CONVENTIONS、两个 Agent 入口和博客维护文档已同步；项目长期维护规则写入 CONVENTIONS。未修改原有共享 memory 的未提交内容。

## 跳转问题与修复

真实浏览器中，从博客进入 `index.html#resources` 后，文章列表异步插入会增加上方高度，导致工具区落点下移，访客仍停在文章区。延迟加载回归在修复前复现约 523px 的桌面偏移。

首页现在会在文章渲染、字体就绪后对初始资源锚点重新定位。用户发生滚轮、触摸、指针或键盘操作，或已切换锚点时，不再恢复位置。监听器随后清理。

新增 `scripts/home-resources-navigation.browser.test.js` 覆盖桌面、手机的延迟加载落点，以及用户主动返回页首后不被拉回。测试固定字体完成和平滑滚动前置条件，避免把初始化动画当作加载偏移。

## 第二轮：三个精选项目与单一入口

根据用户截图反馈完成本地迭代：

- 保留 AI 本地文件助手、多平台资料库、AI 每日情报；Codex 动态监测从首页撤下，仓库继续可由全局 GitHub 入口发现。选择理由和公开文档证据见设计文档第 11 节。
- 每项只保留一个「了解与使用」，全局链接改为「更多 GitHub 项目」；删除重复仓库链接及其无用样式。共三个项目、四个外链。
- 介绍改为具体场景与收益，分别突出本地资料协作、收藏复用和集中阅读信息。文件助手根据 README 中的待验收状态，明确标注「试用版」。本轮核对的是公开文档，未运行这些外部项目。
- 新增 `docs/github-resources-guidelines.md`，规定默认三项、通常二至四项，明确准入条件、成熟度、文案证据、单一入口、替换与撤下规则和维护模板。CONVENTIONS、README、AGENTS、CLAUDE 已引用。
